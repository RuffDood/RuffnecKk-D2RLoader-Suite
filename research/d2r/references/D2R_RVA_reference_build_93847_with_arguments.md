# D2R reverse-engineering RVA catalogue — build 93847 — argument-enriched edition

**Primary build:** D2R 93847.

## How to read the argument column

- `Exact` means the production/probe source contains a concrete function-pointer typedef or an equivalent register-level contract that was used successfully on build 93847.
- `Exact/pass-through` means argument **width/count** is qualified, but some semantic parameter names intentionally remain opaque.
- `Inherited callee ABI` means the RVA is a callsite/return witness, not a callable entry; its useful argument contract is the target function's ABI.
- `N/A` means the RVA is data, a callsite, a comparison/instruction witness, a bridge slot, or another address that should not be invoked as a function.
- `Unknown` is intentional. Calling an address with an invented ABI is much more dangerous than leaving the prototype unresolved.
- D2RLoader 1.3 replaces several StatList/curse entries with `FF 25 rel32` bridges. The documented **D2R entry ABI remains useful**, but chain/resolve the loader-owned bridge instead of hooking the dead retail body.
